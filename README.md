## What I'm building

**[MedVetor](https://medvetor.com.br)**: a SaaS study platform for Brazilian medical licensing (ENAMED) and residency exams, built from scratch and live in production.

- Next.js, React, TypeScript and PostgreSQL (Supabase), serving tens of thousands of questions
- Vetor IA: an AI tutor that reads each student's mistakes, builds a study path and generates new questions on the spot
- AI answers grounded in reviewed content: any number not found in the source is discarded before it reaches the student
- Recurring billing with Stripe (checkout, cancellation, idempotent webhooks) and per-user Row Level Security
- 900+ automated tests plus end-to-end tests (Playwright) before every release

The MedVetor code is private. Happy to walk through the architecture in an interview.
